# Agent Instructions

## Read first

- `README.md` — the entry point: a short summary, how to run it, examples, and checks.
- `docs/adrs/*.md` — major decision and its consequences (only what is relevant to the task).
- `docs/SPEC8N.md` — the authoritative direction, product behaviour, and system shape.
- `docs/DESIGN.md` — the design system, brand styles, colours, typography, and spacing.

## House rules

- Never commit a secret; a configuration file names one, holding no value.
- Never add a second package manager, lockfile, formatter or test runner.
- Write reusable scripts in TypeScript and run them with `bun`.

## Skills

Read the skill whose description covers the work:

- `development` — code changes, the stack, the style, and version control.
- `documenting` — writing README, `docs/SPEC8N.md`, `docs/DESIGN.md`, and ADRs.
